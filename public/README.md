# Public Folder

This folder contains static assets that will be served by Next.js.

## Usage

Files in this folder can be referenced from the root URL. For example:
- `public/logo.png` → `/logo.png`
- `public/images/hero.jpg` → `/images/hero.jpg`

## Common Assets

- Images (`.jpg`, `.png`, `.svg`, etc.)
- Fonts (`.woff`, `.woff2`, `.ttf`, etc.)
- Icons
- Favicon files
- Other static files
